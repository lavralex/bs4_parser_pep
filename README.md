# Проект парсинга pep

## О проекте:

Проект педставляет из себя парсер для поиска и компановки справочной информации о Python, всего доступно 4 режима сбора информации:

***whats_new*** - вернет список ссылок на статьи о нововедениях,соответствующие версий Python, авторов и редакторов 

***latest_versions*** - вернет список ссылок на документацию, соответствующие версий Python и статусы

***download*** - скачивает архив с документацией

***pep*** - вернет список статусов PEP и количество PEP в каждом статусе


## Как запустить 

1) Клонируйте репозиторий: `git clone git@github.com:lavralex/bs4_parser_pep.git`
2) Создайте и активируйте виртуальное окружение
3) Утсановите зависимости 
4) Перейдите в деректорию src и можно использовать

## Как использовать 

`python main.py -h` - команда для вывода вспомогательной информации

Команды данных парсеров строятся по шаблону:  
***python main.py <режим> <опцоональный аргумент> <способы вывода при опцоональном арументе "-o">***

### Доступные режимы: 
***whats-new*** - статьи о нововедениях   
***latest-versions*** -версии Python и документакия  
***download*** - скачивание документации  
***pep*** - статусы PEP и их количество  

### Опцоональные аргументы и их краткая форма:
***-h, --help*** - вспомогательная информация  
***-c, --clear-cache*** - очистка кеша  
***-o {pretty,file}, --output {pretty,file}*** - дополнительные способы вывода данных  

### Cпособы вывода:
***pretty*** - вывод в виде таблички в терминале  
***file*** - вывод в виде csv файла
